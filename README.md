# DartLab 飛鏢投擲分析

用攝影機觀測飛鏢投擲：姿勢鏡頭分析出手動作，靶面鏡頭自動記錄落點，並找出「哪個動作影響落點」。

## 啟動

雙擊 `start.bat`（需要 Python 3），瀏覽器會開啟 http://localhost:8765 ，使用時不要關閉那個黑色視窗。
也可以直接用 Chrome 或 Edge 開啟 `index.html`。首次載入姿勢模型需要連網。

鏡頭打不開時，畫面上會顯示原因：
- **權限被拒**：點網址列左側圖示把攝影機改成「允許」，並確認 Windows 設定 → 隱私權與安全性 → 相機 已開啟。
- **被其他程式占用**：關閉相機 App、LINE、Teams、Zoom、OBS 等正在用鏡頭的程式。
- **找不到攝影機**：裝置選單改選「預設攝影機」。

## 功能

- **姿勢鏡頭**（MediaPipe Pose）：自動偵測每一次出手，量測後拉角、出手角、跟隨延伸、手肘 / 肩膀 / 頭部位移、角速度、節奏等 15 項指標；保留最近 6 投的慢動作骨架回放。可載入手機慢動作影片（設定中選擇 ×4 / ×8 倍率）。
- **靶面鏡頭**：4 點透視校正 → 背景差分自動偵測新飛鏢並計分，可拖曳修正、手動點擊、拔鏢自動辨識。
- **分析**：落點散佈（平均落點、1σ/2σ 橢圓、CEP50）、得分統計、動作一致性評分、手肘角度曲線、指標趨勢、動作 × 落點相關係數、自動教練建議。
- 只有一支鏡頭也能用：在「落點分佈」靶面圖勾選手動記錄，直接點擊落點。
- 資料存在瀏覽器 localStorage，可匯出 CSV / JSON。
